# Twitter Fixer
This is an extension for Twitter (X) that fixes some of the annoyances I've had with it. 
## Installation
1. Download the `.zip` from Releases.
2. Unzip it somewhere it won't get deleted.
3. Go to `chrome://extensions/` and enable Developer Mode.
4. Click Load Unpacked and upload the unzipped folder.
5. Go to Twitter and click on Fixer in the sidebar.
## Features
- Hide Grok and Chat buttons on the bottom right
- Remove ADs for Premium
- Remove Grok buttons
- Show All instead of Posts on profiles
- Fix alignment
- Show View quotes in the repost menu
- Stop the right area from scrolling with the timeline
- Remove blur from the header
- Use default context menu for post media
- Add a download button to video's miniplayer
